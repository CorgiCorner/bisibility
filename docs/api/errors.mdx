---
title: "API errors"
description: "Problem details returned by the bisibility REST API."
---

Errors use `application/problem+json`.

```json
{
  "type": "https://bisibility.com/problems/validation_failed",
  "title": "Validation failed",
  "status": 400,
  "detail": "Request input failed validation.",
  "instance": "urn:bisibility:api:v1:/api/v1/projects/prj_a00000000000000000000000/keywords",
  "docs_url": "https://bisibility.com/docs/api/errors#validation_failed",
  "errors": {}
}
```

| Code | HTTP status | Meaning |
| - | -: | - |
| <span id="bad_request"></span>`bad_request` | 400, 413, or 422 | Request body, query, or JSON could not be parsed, payload is too large, or a required project input is unavailable. |
| <span id="validation_failed"></span>`validation_failed` | 400 | Zod validation failed. |
| <span id="invalid_cursor"></span>`invalid_cursor` | 400 | Pagination cursor is malformed or not a supported v3 cursor. |
| <span id="invalid_public_id"></span>`invalid_public_id` | 400 | A path or payload ID is malformed, has the wrong resource prefix, or is not a public ID. |
| <span id="unauthorized"></span>`unauthorized` | 401 | Missing or invalid bearer API key. |
| `unauthorized` | 419 | Instance import migration token is invalid, expired, or already used. |
| <span id="forbidden"></span>`forbidden` | 403 | API key scope or project scope does not allow the operation. |
| <span id="not_found"></span>`not_found` | 404 | Route or resource was not found. |
| <span id="method_not_allowed"></span>`method_not_allowed` | 405 | HTTP method is not handled by the router. |
| <span id="conflict"></span>`conflict` | 409 | Request conflicts with the current resource state. |
| <span id="self_import"></span>`self_import` | 409 | Instance import package was exported from the destination project itself. |

| <span id="snapshot_expired"></span>`snapshot_expired` | 409 | No unexpired backlinks snapshot is available for the requested continuation. |
| <span id="project_domain_required"></span>`project_domain_required` | 422 | The operation requires a configured project domain. |

## Validation details

Validation errors include an `errors` member with the flattened Zod error
payload:

```json
{
  "fieldErrors": {
    "keyword": ["String must contain at least 1 character(s)"]
  },
  "formErrors": []
}
```

## Rate-limit errors

Rate-limit responses include the same rate-limit headers as successful requests,
plus `Retry-After`.
Upstream provider rate limits also surface as `rate_limited` `429` responses
with `Retry-After`.

```text
Retry-After: 60
RateLimit-Limit: 600
RateLimit-Remaining: 0
RateLimit-Reset: 60
```
