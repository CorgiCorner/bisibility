Use the project's maintained policies and trackers to find help or contribute.

| I need to | Go to |
| - | - |
| Read release notes or download an application release | [Releases](https://github.com/CorgiCorner/bisibility/releases) |
| Check version and API support | [Versioning and support](/versioning) |
| Find a known issue or report a bug | [GitHub issues](https://github.com/CorgiCorner/bisibility/issues) |
| Suggest a feature or documentation correction | [Contribution guide](https://github.com/CorgiCorner/bisibility/blob/main/CONTRIBUTING.md) |
| Report a suspected vulnerability | [Security policy](https://github.com/CorgiCorner/bisibility/blob/main/SECURITY.md) |
| Ask the community | [Discord](https://discord.gg/HcYpvfn79w) |
| Watch product videos | [YouTube](https://www.youtube.com/@bisibility) |

The public repository accepts issues and feedback, but does not accept pull
requests. Follow the contribution guide for the current process.

For a documentation correction, include the page URL, the package or application
version, and what you expected. Remove credentials and customer data from examples.
Suspected vulnerabilities belong in the private disclosure channel described in
the security policy, not in public issues or Discord.

For operating an instance, start with [self-hosting troubleshooting](/self-hosting/troubleshooting)
and [self-hosting security](/self-hosting/security).
