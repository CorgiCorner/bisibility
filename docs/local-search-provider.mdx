Local monitors use a supported DataForSEO connection. Google Maps and Local Finder
are separate sources, with separate result positions and cost estimates. Choose
the source offered by the monitor form; a stored result from one source is not
converted into the other.

## Choose the search context

Set the search language, device, coordinates, and result depth when defining the
monitor. Search language is independent of the app language. The form validates
the supported combination and shows a quote before paid execution.

Changing this context creates a new monitor revision and requires another
spending review. An existing result keeps its original context and observation
date.

## Read positions and coverage

Maps positions use the provider's organic Maps group. Local Finder positions use
the original group order, including advertising slots. Ads remain visible as
evidence but do not count as an organic match. Removing an ad from a view does
not renumber the other positions.

Coordinates are a search seed, not proof of an exact observer location. A missing
listing does not prove absence when coverage is incomplete.

## Costs and incomplete requests

Review the current quote for the selected source and depth. Maps and Local Finder
can have different estimates. Actual charges come from retained provider evidence
and can differ from the estimate.

If a submission response is lost, wait for collection or reconciliation of that
request. Refreshing the page does not submit it again. Project and connection
budgets remain in force.
