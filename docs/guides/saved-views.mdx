title: "Use saved views"

---

Saved views preserve a useful keyword-table query without changing any keyword.

If you want to keep untracked ideas from Research instead, see
[Save keyword ideas](/guides/saved-keywords).

## Save a view

1. Open **Keywords**.
2. Select the location/device lens, search text, and filters you need.
3. In **Saved views**, select the plus button and enter a name up to 48 characters.

A saved configuration includes search text, location and device lens, movement,
last-check state, position buckets, SERP features, tags, topics, intents, search
volume range, and the wrong-URL flag. Applying a view restores those controls in
the URL-backed keyword workspace.

Saved views belong to the project rather than a browser. Other project members
with access can list and use them. Delete obsolete views from the saved-view
control; deleting a view never deletes its matching keywords.

Legacy country, city, and device filter fields are discarded when an old saved
view is read because those dimensions now live in the location/device lens.

Competitor views are separate from keyword views. They preserve the exact
location, desktop or mobile device, Google engine, position and tag filters, and
excluded public keyword IDs. Unsaved competitor exclusions stay in the current
tab through refresh via session storage; the **Unsaved changes** badge offers
explicit save and discard actions.

API routes are listed under
[Saved views](/api/saved-views).
