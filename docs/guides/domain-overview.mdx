Domain Overview can spend the project's connected DataForSEO account. The page
is project-level; it does not follow the header market switcher. Start from
the in-app estimate, then accept the paid report.

## What you need

- A connected DataForSEO account on [Integrations](/integrations).
- Remaining monthly provider budget for a cache miss.

## Run Domain Overview

1. Open **Domain Overview**.
2. Enter a domain or subdomain. A registrable domain uses root scope; a
   subdomain uses subdomain scope unless you override it.
3. Confirm **Country and language** in the module. This is not the header
   market switcher.
4. Review the estimate. Select **Analyze domain**. The button shows `~$X`
   before a paid report, or **Analyze domain free, cached** when the same
   snapshot is already stored.
5. Read the overview metrics, then the keywords and pages tables.

Typical KPIs include Est. traffic, Organic keywords, Top 10, Est. value,
Position #1, and New keywords. Reopening the same snapshot within twelve hours
is free. **Refresh now** pays again. Loading extra table pages or history can
cost more than the first report.

Individual keyword or page modules can fail while the rest of the report
remains usable. If the provider index does not cover the selected country and
language, rank tracking is unaffected.

Published client entry points for this module are listed under
[Domain Overview client support](/compatibility). API request shapes stay on
[Domain Overview](/api/domain-overview).
