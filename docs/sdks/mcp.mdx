An MCP server lets an MCP-compatible AI client call bisibility operations as
tools instead of composing HTTP requests itself.

## Install

```bash
npm install @bisibility/mcp
```

## Authenticate

The local stdio server reads the API root and credential from its environment:

```bash
export BISIBILITY_API_KEY="your-api-key"
export BISIBILITY_BASE_URL="https://your-host.example/api/v1"
```

It accepts project API keys and
[personal access tokens](/api/personal-access-tokens).

The hosted Streamable HTTP server is available at:

```text
https://bisibility.com/api/mcp
```

MCP clients that support OAuth discover the authorization flow automatically.
bisibility uses Authorization Code with PKCE, dynamic client registration, and
access tokens bound to the MCP resource. API keys and personal access tokens
remain available for clients that manage bearer credentials directly.

## Connect a client

The runnable quickstart starts the package's stdio server, connects a client,
checks the advertised tools, and makes the first
`list_projects` call:

{/* docs-example:start mcp-client-usage */}
{/* Generated from examples/mcp/quickstart.mjs (region client-usage). Do not edit. */}
```javascript
const launch = serverLaunch();
const transport = new StdioClientTransport({
  args: launch.args,
  command: launch.command,
  env: {
    ...process.env,
    BISIBILITY_API_KEY: requiredEnv("BISIBILITY_API_KEY"),
    BISIBILITY_BASE_URL: requiredEnv("BISIBILITY_BASE_URL"),
  },
});
const client = new Client({ name: "bisibility-mcp-example", version: "0.1.0" });

try {
  await client.connect(transport);

  console.log("Listing MCP tools");
  const tools = await client.listTools();
  const names = new Set(tools.tools.map((tool) => tool.name));
  for (const toolName of expectedTools) {
    assert(names.has(toolName), `Missing MCP tool ${toolName}.`);
  }
  assertToolParity(tools.tools, await listHttpTools());

  console.log("Calling list_projects");
  const result = await client.callTool({
    arguments: {},
    name: "list_projects",
  });
```
{/* docs-example:end mcp-client-usage */}

That tool performs the documented
[`GET /projects`](/api/projects#list-projects) read.
