## Install

```bash
go get bisibility.com/sdk-go
```

The current docs-tested module is `bisibility.com/sdk-go v0.10.0`. See
[Versioning and support](/versioning).

## Authenticate

Keep the API root and credential in environment variables:

```bash
export BISIBILITY_API_KEY="your-api-key"
export BISIBILITY_BASE_URL="https://your-host.example/api/v1"
```

The client accepts project API keys and
[personal access tokens](/api/personal-access-tokens).

## List projects

This copyable quickstart constructs the client and lists projects. Paste it
into a fresh file after the install and environment steps above:

{/* docs-example:start go-client-usage */}
{/* Generated from examples/go/list-projects/main.go. Do not edit. */}
```go
package main

import (
	"context"
	"fmt"
	"os"

	bisibility "bisibility.com/sdk-go"
)

func main() {
	apiKey := os.Getenv("BISIBILITY_API_KEY")
	baseURL := os.Getenv("BISIBILITY_BASE_URL")
	if apiKey == "" || baseURL == "" {
		fmt.Fprintln(os.Stderr, "Set BISIBILITY_API_KEY and BISIBILITY_BASE_URL before running this example.")
		os.Exit(1)
	}

	client, err := bisibility.NewClient(
		bisibility.WithAPIKey(apiKey),
		bisibility.WithBaseURL(baseURL),
	)
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}

	projects, err := client.ListProjects(context.Background())
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}

	for _, project := range projects.Data {
		fmt.Println(project.ID, project.Domain)
	}

	fmt.Println("OK go-list-projects")
}
```
{/* docs-example:end go-client-usage */}

A successful run prints each project id and domain, then `OK go-list-projects`.

See [`GET /projects`](/api-reference/projects/list-projects-visible-to-this-api-key)
for the request and response contract.

The [complete Go example](https://github.com/CorgiCorner/bisibility/blob/main/examples/go/quickstart/main.go)
also creates a keyword, runs a rank check, and cleans up.
