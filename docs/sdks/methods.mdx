Tracking previews never submit paid provider work. Launch and retry require explicit consent,
reviewed preview revisions, and a stable retry key. Export returns bounded JSON evidence with
completeness and continuation metadata by default; select CSV explicitly. Prompt Research suggestions read saved project context and competitors, remain
editable hypotheses, and become Prompt Tracker prompts only after acceptance. Unknown costs stay null decimal USD
amounts, and cached observations keep their original timestamps.

Model generation first freezes the complete reviewed context, selected competitors, model and
market. Generation requires that unexpired preview, explicit paid consent and a stable UUID
retry header. The forecast is not a guaranteed maximum. Edited hypotheses retain a verified
generation and draft reference; provider dataset prompts require a verified stored report row.

## Page indexing methods

Stored URL lists include current sitemaps and keyword targets. Request
`source=manual` explicitly for manual-only URLs. Filter missing Google reasons
with `coverage_state=Unspecified`; synthetic reasons have null coverage state
and use the group filter alone. `inspection_failed_at` records the last failed
attempt independently of the last Google result time in `checked_at`.


These contract mappings return Google's indexed state as already known to Google,
not a live test. Results may be partial or delayed. Use the project's existing
connection; no property override is accepted. Client package support depends on
version. See [Page indexing](/api/search-index) for REST requests and error handling.

| Source operation | Python | TypeScript | Go | MCP tool |
| - | - | - | - | - |
| List Page indexing sitemaps | `list_search_index_sitemaps` | `listSearchIndexSitemaps` | `ListSearchIndexSitemaps` | `list_search_index_sitemaps` |
| Get a Page indexing sitemap | `get_search_index_sitemap` | `getSearchIndexSitemap` | `GetSearchIndexSitemap` | `get_search_index_sitemap` |
| Inspect Page indexing URLs | `inspect_search_index_urls` | `inspectSearchIndexUrls` | `InspectSearchIndexUrls` | `inspect_search_index_urls` |
| Read Page indexing report | `get_page_indexing_report` | `getPageIndexingReport` | `GetPageIndexingReport` | `get_page_indexing_report` |
| List Page indexing URLs | `list_page_indexing_urls` | `listPageIndexingUrls` | `ListPageIndexingUrls` | `list_page_indexing_urls` |
| Read Page indexing settings | `get_page_indexing_settings` | `getPageIndexingSettings` | `GetPageIndexingSettings` | `get_page_indexing_settings` |
| Update Page indexing settings | `update_page_indexing_settings` | `updatePageIndexingSettings` | `UpdatePageIndexingSettings` | `update_page_indexing_settings` |

Inspection requires write scope, accepts 1-10 URLs and returns per-URL errors.
URLs are normalized; duplicates after normalization count once. Manual and
background inspections share one project daily allowance that resets at midnight
Pacific time (`America/Los_Angeles`), including daylight saving changes.
Every URL sent counts even on failure; admitted URLs not sent after a batch stops
are released. This application allowance is not Google's quota and may change.
`provider_rate_limited` errors include `reset_at` and `scope` (`daily`, `minute` or
`unknown`); no further URLs in the request are sent.
