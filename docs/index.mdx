## Base URLs

Use the regional API root shown by your project. The EU hosted region currently uses:

```text
https://eu.bisibility.com/api/v1
```

Call the regional host directly instead of relying on a redirect from the
marketing domain.

For a self-hosted instance, use your own app origin with the same path:

```text
https://rank.example.com/api/v1
```

Browser code running inside the app can use a relative base URL:

```text
/api/v1
```

## What is documented

The API reference documents routes handled by `app/api/v1/[[...path]]`,
`app/api/v1/cloud/import`, and `lib/api/*`. OpenAPI is
generated from `lib/api/openapi.ts` and includes the instance-import compatibility,
single-request, and chunked-session flows.
