# Changelog

All notable changes to the Bisibility Claude Code plugin are documented here.

## [0.5.0] - 2026-10-23

- Added AI prompt research with saved/free evidence reuse, explicit non-guaranteed model-cost consent and separately approved Prompt Tracker writes.

- Added domain onboarding, the skill router, keyword import, weekly report, provider setup, team API governance and self-host health so every published workflow installs with the skills CLI.
- Documented `npx skills add CorgiCorner/bisibility` as the command that installs all skills for Agent Skills clients.
- Keyword clustering stays SERP-free by default and can record a SERP-assisted comparison only from user-supplied result URLs.
- Keyword opportunity research starts with connected Search Console queries before any paid seed.
- SEO audit reports keep Search Console history, current rank observations and crawl results in separate evidence classes.
- Competitor analysis classifies page format and treats a title-and-URL class as preliminary.
- SEO coach and the router send research and a tracking choice ahead of keyword import or project setup.
- Added local SEO from retained Local monitor runs. The skill does not create monitors, launch runs or read a business profile.

## [0.4.0] - 2026-10-16

- Added keyword clustering, single-competitor analysis and competitive landscape skills with confirmed markets, evidence limits and estimate-first total budget plans.
- Added shared saved-report fixture contracts, routing cases and install catalog availability for the three skills.

## [0.3.0] - 2026-10-16

- Added project setup, SEO coach, AI visibility audit and alert triage skills with confirmed writes and estimate-first cost controls.
- Added tool-name validation, routing evals and localized install catalog entries for the expanded plugin.

## [0.2.0] - 2026-10-05

- Added an external-agent SEO audit workflow using the bounded crawl and saved ranking/AI evidence, with prioritized actions, AgentReport persistence and an access-controlled project link.
- Added report payload validation, fixtures and contract checks; documented partial results, observed versus synthetic evidence, permissions and paid-action approval.

## [0.1.0] - 2026-08-04

- Added the OAuth-protected remote MCP connection.
- Added rank tracking report, keyword opportunity research, and backlink profile analysis skills.
- Added a committed positive and negative routing eval corpus for all three skills.
- Licensed the plugin package separately under the MIT License.
