# Changelog

All notable changes to the Bisibility Claude Code plugin are documented here.

## [0.4.0] - 2026-10-16

- Added keyword clustering, single-competitor analysis and competitive landscape skills with confirmed markets, evidence limits and estimate-first total budget plans.
- Added shared saved-report fixture contracts, routing cases and install catalog availability for the three skills.

## [0.3.0] - 2026-10-16

- Added project setup, SEO coach, AI visibility audit and alert triage skills with confirmed writes and estimate-first cost controls.
- Added tool-name validation, routing evals and localized install catalog entries for the expanded plugin.

## [0.2.0] - 2026-10-05

- Added an external-agent SEO audit workflow using the bounded crawl and saved ranking/AI evidence, with prioritized actions, AgentReport persistence and an access-controlled project link.
- Added report payload validation, fixtures and contract checks; documented partial results, observed versus synthetic evidence, permissions and paid-action approval.

## [0.1.0] - 2026-08-04

- Added the OAuth-protected remote MCP connection.
- Added rank tracking report, keyword opportunity research, and backlink profile analysis skills.
- Added a committed positive and negative routing eval corpus for all three skills.
