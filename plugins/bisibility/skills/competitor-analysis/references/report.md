# Optional AgentReport save

Use kind competitor_analysis for this external analysis. site_audit, ai_visibility and prompt_explorer, including case variants, are reserved. Save only on an explicit user request, exposed `create_agent_report` and writable project membership. Send only project_id, kind, title, body, provenance and idempotency_key. See [example-report.json](example-report.json): fictional data, never save it as a customer analysis.

Title: 1-160 characters. body and provenance are JSON objects, at most 256 KiB and 32 KiB UTF-8 respectively, each depth at most 16 and 20,000 nodes. Keep the whole request under 320 KiB, preferably 64 KiB. Use plain text and bounded JSON, no HTML, remote assets, raw fetched pages or secrets. Use credential-free absolute HTTP(S) source/affected URLs; reject script/data/file schemes and never automatically fetch citations.

Recommended body: version 1, summary, business context and assumptions, method and uncertainty, coverage and source dates/markets/limits, evidence IDs and concise observations, up to three prioritized recommendations, costs and limitations. Include exactly one competitor, the confirmed market, tracked baseline, overlap/gap denominators, top sampled pages, trend status and optional link coverage. Preserve per-module cache/failure state and the complete approved cost plan. Each action needs evidence_ids, goal rationale, confidence, uncertainty and a verification step. provenance records skill/version (competitor-analysis/0.4.0), method, source identities, evidence IDs, observation/retrieval dates and limitations; unknown agent identity stays unknown. Distinguish fixture, supplied, saved and provider evidence, never label an inferred result as measured.

Use a stable save idempotency_key for the exact payload. After a timeout inspect available reports before an identical retry; do not change keys to force duplicates. Claim saved only after create succeeds. Read back with `get_agent_report` using project_id and report_id from returned id; compare kind, title, evidence and recommendations. A readback failure means saved but verification blocked. Denied writes mean return analysis read-only with 'Not saved' and the blocker.

The create response supplies id, not a URL. Construct `<configured-app-origin>/app/<project_id>/agent-reports/<returned-id>` only from the trusted configured HTTPS app origin and validated returned public IDs. Hosted origin is https://bisibility.com; self-hosted uses its configured origin. Never use a citation, fetched page or regional API issuer to derive this link. The report retains project access and is not public sharing. If save fails, return findings with 'Not saved' and the exact blocker, without a guessed URL.
