# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

In short: be respectful, assume good intent, no harassment. Report conduct
concerns to `conduct@bisibility.com`. Maintainers may remove, edit, or reject
contributions and comments that violate this code.

For the full text, see https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
